# IBM Plex Sans

The chart font of TreeTime: IBM Plex Sans, the interface typeface of the neherlab design language (`packages/design`), which the web app loads through `@fontsource-variable/ibm-plex-sans`. `treetime-charts` embeds the static Regular and Bold instances, draws chart text with them, and subsets them into PDF charts. The charts need static instances, because the chart library and the PDF writer draw a variable font only at its default weight.
