# Lato

The chart font of TreeTime: the Lato family of the Google Fonts repository, the same design that the web app loads through `@fontsource/lato`. `treetime-charts` embeds these files, draws chart text with them, and subsets them into PDF charts.

- Source: [`google/fonts`](https://github.com/google/fonts), folder [`ofl/lato/`](https://github.com/google/fonts/tree/5d3b76120a319730fda218cc7410174a462b32cb/ofl/lato) at commit `5d3b76120a319730fda218cc7410174a462b32cb`
