## Hydrated island

This disclosure carries `client:visible`, so the browser loads its JavaScript when it scrolls into view. It is the collapsible of the app.

<Disclosure title="What the clock rate means" client:visible>
  The clock rate is the number of substitutions per site per year. TreeTime estimates it from the sampling dates of the
  tips.
</Disclosure>

## When a page needs an island

A component needs an island only when it reacts to the reader: it opens, filters, switches, or remembers a choice. A component that only shows content renders at build time and costs the reader nothing.
