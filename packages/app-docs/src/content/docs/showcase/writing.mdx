:::note
This page lists the syntax of the docs features. Its examples use placeholder text.
:::

## Pages

Pages are `.mdx` files in `packages/app-docs/src/content/docs/`, and German translations are in its `de/` folder. The front matter sets `title`, and optionally `description`, `template` (`doc` or `splash`), `tableOfContents`, and `editUrl: false`. A `meta.json` file sets the title of a folder and the order of its pages.

## Links

Write links from the root of the docs, without the version: `[math](/showcase/math)` links to the math page of the version and the language of the reader. Files of the public folder work the same way: `![logo](/logo.svg)`.

## Callouts

```md
:::note
A note.
:::

:::tip[A custom title]
A tip with a title.
:::
```

The types are `note`, `tip`, `warning`, and `danger`. Another type stops the build.

## Steps

Each heading that starts with a number and a dot becomes a step:

```md
### 1. Prepare the inputs

### 2. Run the analysis
```

## Synced tabs

Tabs need an import and the `client:load` directive. Each tab is one named slot, `tab-0`, `tab-1`, and so on, in the order of the labels:

```mdx
import { SyncedTabs } from "../../../components/SyncedTabs";

<SyncedTabs syncKey="surface" labels={["CLI", "Web app"]} client:load>
  <div slot="tab-0">Text for the CLI.</div>
  <div slot="tab-1">Text for the web app.</div>
</SyncedTabs>
```

Groups with the same `syncKey` switch together.

## Disclosures

```mdx
import { Disclosure } from "../../../components/Disclosure";

<Disclosure title="A question" client:visible>
  The answer.
</Disclosure>
```

## File trees and cards

`FileTree`, `LinkCard`, and `CardGrid` need no import:

```mdx
<FileTree entries={[{ name: "out", children: [{ name: "dates.tsv", note: "node dates" }] }]} />

<CardGrid>
  <LinkCard title="Math" description="Inline and display math." href="/showcase/math" />
</CardGrid>
```

## Math

Write inline math as `$\mu$` and display math in `$$` blocks. Number an equation with `\tag{1}`, and put an anchor before the block so a sentence can link to it:

```mdx
<a id="eq-jc69"></a>

$$
P_{ii}(t) = \tfrac{1}{4} + \tfrac{3}{4} e^{-4t/3} \tag{1}
$$

Equation [(1)](#eq-jc69) gives the transition probabilities.
```

Shared macros, such as `\Tc` for $\Tc$, are in `packages/app-docs/src/math/macros.ts`. Follow each display equation with a list that declares its symbols.

## Code

A code block takes a `title`, `frame="terminal"`, line markers such as `{2}`, `ins={3}`, and `del={4}`, and `wrap` for long lines. A `diff` block takes `lang` for the highlighting of its lines.

## Islands

An interactive component needs a `client:` directive (`client:load`, `client:idle`, `client:visible`) and an import in the page itself, because the directive works only on components that the page imports. Static app components need no directive.

## Generated pages

The settings pages and the command-line reference are generated. Change the help texts in the Rust source and run `just gen`, never edit these pages by hand.
