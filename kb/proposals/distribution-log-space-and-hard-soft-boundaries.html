Distribution log-space and hard/soft boundaries

Visual companion to kb/proposals/distribution-log-space-and-hard-soft-boundaries.md

1. Branch-length likelihood L(t | n, μ)

The substitution likelihood for a branch of length t (subs/site) with n observed mutations at total rate μ = clock_rate × L:

L(t) ∝ (μt)n e−μt

This is evaluated on a uniform grid by compute_branch_length_distribution() and stored as a Distribution::Function. The grid spans [0.01·one_mutation, max(5·center, 10·one_mutation)].

Plain probability space

11

Neg-log space y = −log L(t)

Lower = more probable. The tail is asymptotically linear with slope μ. For n ≥ 1 the curve diverges as −n log t → +∞ near the origin.

create_simple_grid() floors at min_bl = 0.01 · one_mutation, so t = 0 is never on the grid. For n = 0 the mode sits at t = 0 (the density is maximal there), but the grid starts past it. For n ≥ 1 the density vanishes at the boundary, so the floor avoids storing +∞ in neg-log space.

2. Message to parent: convolution m(tp) = δ(tc) ∗ (−L)

A leaf's date constraint (point or narrow distribution at the sampling date) is convolved with the negated branch-length likelihood. The result is a distribution over the parent's time: m(tp) = ∫ p(tc) · L(tc − tp) dtc. The backward pass attaches Constant left / Zero right tails to this message.

Convolution components and result

0.89

Leaf fixed at 2023.0. For the Ebola dataset with μ = 11.24 muts/yr, the grid extent is 10 / μ ≈ 0.89 yr for zero-length branches. Drag the slider to see how wider grids change the message extent.

Boundary semantics on the message

Right edge: Zero (hard) -- the parent cannot postdate the child's sample. Left edge: Constant (soft) -- the branch could be longer than the grid represents. Proposed: the soft side carries a Linear law (log-linear decay) instead of a flat constant.

3. Backward pass: child message multiplication

At each internal node, the backward pass multiplies all incoming child messages: p(tnode) ∝ ∏c mc(tnode). Currently multiply_function_function() intersects grid bounds via multiplication_support_intersection(), which extends Constant tails to the other operand's bound but treats Zero and Error as hard stops.

Overlapping grids (normal case)

Children 0.5 yr apart. Grids overlap. The product concentrates probability where both messages agree.

Disjoint grids (the defect)

Children 3 yr apart. Grid extents < 0.89 yr each. distribution_support_intersection() returns Disjoint. Result: Distribution::empty(). The Constant left tail was attached but multiplication_support_intersection only extends Constant tails -- the Zero right tail of the accumulator blocks rightward extension.

Node 603 in the Ebola dataset: accumulator [2021.55, 2022.42], next child message [2024.68, 2025.57]. The 2.26-year gap exceeds both grid extents. multiply_function_function returns Empty. Four such collapses seed 58 empty internal nodes including the root, leaving all 471 internal nodes without num_date across both iterations. compute_positional_log_lh() skips every edge, returns None, and the metric prints NaN.

4. Proposed fix: hard/soft boundary multiplication rule

Classify each boundary as hard (domain terminates, probability is zero beyond) or soft (grid stops but an analytic law continues). The multiplication rule per side:

Hard: result bound = tightest (innermost) hard bound among operands.
Soft: result bound = loosest (outermost) soft bound among operands.
Mixed: a hard bound dominates a soft bound on the same side.

Each operand is evaluated over the result domain, using its declared tail law wherever the query falls outside its own grid.

Disjoint case resolved with soft tails

Left bound: both soft → take the loosest (2021.55). Right bound: both hard → take the tightest (2022.42). Child 2's message is evaluated via its Linear tail law across the gap. Product peaks at the hard right edge: parent placed at the earlier child's date, later child absorbs a ~3.15 yr branch.

Multi-child accumulation with normalization

4

In plain space, the peak decays as (peak)N without intermediate normalization. In neg-log space multiplication is addition: exact, associative, no underflow. The per-step normalize() in the child fold becomes unnecessary.

5. Near hard boundaries: power-law approach region (Part C)

Near a hard boundary at thard, the density follows a power law p(t) ∝ (t − thard)n. In neg-log space:

y(t) = −n · log(t − thard) + μt + C

Proposed two-parameter approach law fit from the innermost grid points by least squares on (log(t − thard), y):

y(t) = a − b · log(t − thard),   b ≥ 0

Plain probability near t = 0

n = 0: mode at t = 0, step discontinuity (density = e0 = 1). n = 1: linear vanishing. n = 3: cubic. Dashed line: first grid point min_bl = 0.01/μ.

Neg-log space near t = 0

b = 0 (n = 0): finite minimum at boundary, mode preserved exactly. b > 0 (n ≥ 1): logarithmic divergence. The approach law is a straight line on these (log t, y) axes. Mass in the approach region: ∫ exp(−y) dt = exp(−a) · Δtb+1 / (b+1) (closed form).

Storing y(thard) = +∞ for n ≥ 1 poisons the first grid cell: linear interpolation from +∞ returns +∞ across the cell, zeroing the density in plain space. Grid placement rule: when b > 0, the grid stays strictly inside the hard boundary; when b = 0, the boundary value is finite and stored as an exact endpoint.

6. Distribution lifecycle: leaf to root

How a leaf's sampling date propagates through the timetree inference passes.

Distributions at each inference stage

(1) Leaf date constraint δ(tsample) or narrow distribution for uncertain dates. (2) Branch-length likelihood L(t) from substitution counts. (3) Message to parent: m = constraint ∗ (−L), tails: Constant left, Zero right. (4) Accumulated posterior at parent: ∏c mc. (5) Coalescent weight applied: p · exp(−wcoal). (6) Forward-pass cavity: divide out this child's contribution to refine the parent's marginal.
