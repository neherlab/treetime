# Initial branch-length guess allocates Vec<Sub> per edge for count only

`InitialGuessEvidence::gather()` ([packages/treetime/src/optimize/gather.rs#L73-L84](../../packages/treetime/src/optimize/gather.rs#L73-L84)) counts the substitutions of each edge by calling `edge_subs()` and taking `.len()`, discarding the substitution vector. The optimize pipeline gathers this evidence before the loop, in `fn apply_initial_guess()` ([packages/treetime/src/optimize/pipeline.rs#L198](../../packages/treetime/src/optimize/pipeline.rs#L198)) and passes the counts to `fn guess_initial_branch_lengths()` ([packages/treetime/src/optimize/dispatch.rs#L176](../../packages/treetime/src/optimize/dispatch.rs#L176)). For dense partitions, `edge_subs()` ([packages/treetime/src/partition/marginal/dense/partition.rs#L77](../../packages/treetime/src/partition/marginal/dense/partition.rs#L77)) builds a `Vec<Sub>` with one entry per differing site. The count runs across every edge before optimization. The dense branch of `edge_sub_count()` ([packages/treetime/src/partition/marginal/reconstruction.rs#L291-L296](../../packages/treetime/src/partition/marginal/reconstruction.rs#L291-L296)), which timetree polytomy resolution uses, counts the same way.

A count-only method (incrementing a counter instead of pushing `Sub` values) would avoid the allocation. For small alignments the cost is negligible. For large alignments (thousands of positions, hundreds of edges) the cumulative allocation is avoidable.

## Proposed implementation plan

1. Add `fn edge_sub_count()` to the dense partition in `packages/treetime/src/partition/marginal/dense/partition.rs` beside `edge_subs()`, sharing one iterator over differing sites so the two cannot diverge: `edge_subs()` collects it, `edge_sub_count()` counts it.
2. Call the count method from `InitialGuessEvidence::gather()` in `packages/treetime/src/optimize/gather.rs` (line 80) and from the dense branch of `PartitionMarginal::edge_sub_count()` in `packages/treetime/src/partition/marginal/reconstruction.rs`.
3. Test: an `rstest` in the dense partition's `__tests__/` that asserts `edge_sub_count() == edge_subs().len()` on a small hand-made tree with zero, one, and several differing sites, including ambiguous characters (oracle: the length of `edge_subs()`, an independent collection path of the same site iterator, plus the hand-counted differences).
4. Validate with `just lint-rs` and `just test-rs`; outputs are unchanged by construction, so no smoke run.
