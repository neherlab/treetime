# `flu/h3n2/500`

476 neuraminidase (NA) sequences of seasonal influenza A/H3N2 sampled from 1968 to 2013, the coding sequence of the NA reference CY114383 (A/Wisconsin/67/2005) without its stop codon, in frame from site 1.

## Metadata

`metadata.tsv` holds the columns `name`, `date`, and `location` (the sampling country), and a `region` column: the region of each country in the table `config/geo_regions.tsv` of the Nextstrain seasonal-flu workflow, which groups countries as the influenza builds do (`China`, `JapanKorea`, `SoutheastAsia`, `WestAsia`, ...).
